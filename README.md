# 매지션 스토리 🧙‍♀️🐈

견습 마법사가 마탑의 시험을 치르며 **초급 → 중급 → 상급 → 익스퍼트** 마법사로 성장하는 픽셀 액션 RPG예요.
고양이 캐럿과 함께 몬스터를 잡아 장비와 골드를 모으고, 아홉 원소 가운데 나만의 길을 골라 스킬을 키워 마지막에는 재앙의 용을 다시 잠재워요.

**하러 가기:** https://mhyoo-games.github.io/MagicianStory/

## 이야기 (8장)
오백 년 전 아홉 원소의 대마법사가 봉인한 재앙의 용 아즈다하. 봉인을 지키는 마법사 마을 루미나에서, 견습 마법사가 첫 지팡이를 받는 날부터 이야기가 시작돼요.

| 장 | 들판 → 던전 | 중간보스 | 보스 | 시험 |
|---|---|---|---|---|
| 1 견습의 첫걸음 | 초록 숲 → 고블린 굴 | 킹 슬라임 | 고블린 족장 그락 | 초급 |
| 2 안개 늪의 속삭임 | 안개 늪 → 가라앉은 사원 | 리자드맨 전사장 | 늪의 마녀 모르가 | |
| 3 불꽃 협곡 | 붉은 협곡 → 용암 동굴 | 오크 광전사 | 오크 대족장 볼그 | 중급 |
| 4 얼어붙은 봉우리 | 서리 산길 → 빙결 궁전 | 서리 늑대왕 | 빙결의 여왕 세레스 | |
| 5 바람의 탑 | 구름 다리 → 탑 꼭대기 | 폭풍 그리폰 | 바람의 집행자 카이 | 상급 |
| 6 가라앉은 도서관 | 잠긴 서고 → 금서고 | 금서 「검은 장」 | 리치 네크로스 | |
| 7 시간의 미궁 | 모래시계 사막 → 시간의 미궁 | 시계탑 수호자 | 교단장 발타르 | 익스퍼트 |
| 8 용의 둥지 | 불타는 화산길 → 용의 둥지 | 검은 와이번 | **재앙의 용 아즈다하** | |

- 장마다 사냥 · 퀘스트 물건 모으기 · 중간보스 · 던전 보스 순서로 진행하고, 마을 사람과 이야기하며 다음 장이 열려요.
- 보스는 체력이 절반 아래로 내려가면 성나서 더 빨라져요. 바닥의 빨간 원은 곧 공격이 떨어지는 자리예요.
- 한 번 깬 보스는 다시 찾아가면 또 싸울 수 있어요 (장비 파밍).

## 전직 시험 · 원소 루트
- 별빛 마탑에서 시험관을 제한 시간 안에 이기면 계급이 올라요: 견습 → 초급(1장) → 중급(3장) → 상급(5장) → 익스퍼트(7장).
- 처음에 원소 **하나**를 고르고, 시험에 붙을 때마다 원소를 하나씩 더 고를 수 있어요 (최대 다섯).
- 원소 아홉: 🔥 불 · 💧 물 · ❄️ 얼음 · 🌪️ 바람(번개 포함) · 🌑 어둠 · ✨ 빛 · 🌿 나무 · 🪨 흙 · ⏳ 시간
- 몬스터마다 약한 속성(1.5배)과 강한 속성(0.6배)이 있어요.

## 스킬 200개
- 원소마다 22개 (견습 2 · 초급 5 · 중급 5 · 상급 5 · 익스퍼트 5) + 공용 2 (마나 실드, 블링크).
- 종류: 탄 · 부채꼴 · 주위 폭발 · 지점 폭발 · 쏟아지는 비 · 관통 줄기 · 장판 · 도는 구슬 · 연쇄 번개 · 강화 · 회복 · 순간 이동 · 늘 켜짐.
- 상태 이상: 화상 · 중독 · 느려짐 · 얼림 · 속박 · 기절 · 밀쳐냄 · 방어 약화 · 흡혈 · 눈부심.
- 스킬마다 레벨 1~5. 레벨이 오르면 스킬 점수 1, 시험에 붙으면 3점을 더 받아요. 「망각의 물약」으로 점수를 되돌릴 수 있어요.

## 장비 200개
| 칸 | 수 | 주로 오르는 능력 |
|---|---|---|
| 지팡이 | 56 | 마력, 속성 피해 (기본 공격이 지팡이 속성으로 나가요) |
| 모자 | 28 | 마나, 재사용 감소 |
| 로브 | 28 | 체력, 방어 |
| 신발 | 24 | 이동 속도 |
| 반지 | 32 | 마력, 치명타 |
| 목걸이 | 32 | 체력·마나, 회복, 흡혈 |

- 8단계(장마다 한 단계) × 등급 일반 · 고급 · 희귀 · 영웅 · 전설.
- 상점(지팡이 공방 · 의상실 · 약초 가게 · 잡화점)에서 사거나, 몬스터 드랍, 보스 고유 장비로 얻어요. 보스를 처음 쓰러뜨리면 전설 장비를 꼭 줘요.
- 모자·로브·지팡이를 바꾸면 주인공 그림의 색도 바뀌어요.

## 조작
| 할 일 | 키보드 | 휴대폰 |
|---|---|---|
| 움직이기 | 방향키 · WASD | 왼쪽 조이스틱 |
| 기본 공격 (가까운 적 자동 조준) | Space · J | 공격 단추 |
| 스킬 | 1 ~ 6 | 스킬 단추 |
| 물약 | Q 체력 · E 마나 | ❤️ 💙 |
| 말 걸기 · 상점 | F · Enter | 말하기 |
| 가방 · 스킬 · 능력치 · 이야기 | B · K · C · N | 위쪽 단추 |
| 메뉴 · 닫기 | Esc | ⚙️ |

저장은 브라우저에 자동으로 돼요.
